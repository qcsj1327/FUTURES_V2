# v0.4 Domain Migration: ExecutionResult Partial Fill Fields

## 背景

v0.3-execution-realism 已完成：

- slippage
- order id generation
- rejection policy

下一步 partial fill 不能通过 reason / metadata 隐式表达，必须显式扩展 ExecutionResult。

## 变更

### ExecutionStatus 新增

| 字段 | 值 | 语义 |
|---|---|---|
| PARTIALLY_FILLED | partially_filled | 部分成交 |
| FILLED | filled | 完全成交 |

保留：

| 字段 | 值 | 语义 |
|---|---|---|
| SUBMITTED | submitted | 已提交 |
| REJECTED | rejected | 被拒绝 |

### ExecutionResult 新增字段

| 字段 | 类型 | 语义 |
|---|---|---|
| filled_quantity | float \| None | 本次成交数量 |
| remaining_quantity | float \| None | 剩余未成交数量 |
| avg_fill_price | float \| None | 平均成交价格 |

## 语义约束

- REJECTED：filled_quantity / remaining_quantity / avg_fill_price 可为 None
- PARTIALLY_FILLED：filled_quantity > 0 且 remaining_quantity > 0
- FILLED：filled_quantity > 0 且 remaining_quantity = 0
- State / Capital 后续必须使用 filled_quantity，而不是 order.quantity
- 禁止用 reason / metadata 编码成交数量

## 迁移边界

本次提交只做 Domain Migration，不接入 broker / state / capital 行为。

后续提交再实现：

- broker partial fill
- StateEngine 按 filled_quantity 更新 position
- CapitalModel 按 filled_quantity 计算 cash_delta
